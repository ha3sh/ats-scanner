# Agent guide

- Read `docs/ARCHITECTURE.md` first; it is the plan of record. Keep the folder
  tree and layer rules shown there.
- OS is Windows; drive everything through [uv](https://docs.astral.sh/uv/).
  No Makefile — use `uv run poe <task>` (see `[tool.poe.tasks]` in
  `pyproject.toml`).
- `src/ats_scanner/core/` is pure: no FastAPI, no pdfplumber/python-docx, no
  HTTP clients, no file or network I/O. Adapters own parsing; `main.py` owns
  wiring; `api.py` owns transport. A guard test in `tests/` enforces this.
- `src/ats_scanner/static/` is generated by the Vite build and committed; never
  hand-edit it.
- Run `uv run poe check` before finishing any change.
